# Roadmap

What is planned for kyouyou (共有). Items move to the [changelog](CHANGELOG.md) when released.

## Now

- Every project publishes its version, changes, roadmap and features as `project.json`, read by the hub dashboard.

## Next

- A shared runway matcher for the apps, so a procedure, a plan and the sim agree on which runway is meant.
- Minimum sector altitudes from the FAA's procedure file, for apps without the user's X-Plane data.

## Later

- Reading navigation data from a user's own licensed database, kept on their device.
- Shared weather caching for the Kuukou server.

## Not planned

- Shipping any navigation data with the package.
